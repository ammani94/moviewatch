# MovieWatch

Une application web permettant aux utilisateurs de **créer un compte**, **ajouter des films et séries à leurs favoris**, et **découvrir des contenus** en utilisant l'API [TMDB](https://www.themoviedb.org/).

---

## 🎯 Fonctionnalités

- **Authentification** : Inscription et connexion sécurisée pour gérer son profil.
- **Gestion des favoris** : Ajoute des films et séries à une liste de favoris personnelle.
- **Exploration** : Parcoure les films et séries populaires, avec leurs détails.

---

## 🛠 Technologies utilisées

- **Frontend** : Développé avec **Next.js** pour une interface réactive et moderne.
- **Backend** : API Node.js/Express pour gérer les requêtes utilisateur et les interactions avec TMDB.
- **Base de données** : MongoDB pour stocker les utilisateurs et leurs favoris.
